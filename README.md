# 合金弹头 × 魂斗罗：丛林行动

Marco Rossi 进入魂斗罗 NES 第一关，从丛林起点经过两座爆破桥、高低平台，打到关底堡垒并摧毁核心。纯 HTML、CSS、JavaScript 浏览器游戏，无需安装依赖。

## 操作

| 按键 | 动作 |
|---|---|
| A / D 或 ← / → | 移动 |
| 空格 / K / W | 跳跃，按住跳得更高 |
| J | 射击 |
| Q | 循环切换有弹药的武器 |
| 1 / 2 / 3 | 手枪 / 重机枪 / 火箭筒 |
| L | 投掷手榴弹 |
| ↓ / S | 蹲下；配合跳跃下穿平台 |
| ↑ | 向上射击，配合移动可斜向上射击 |
| P | 暂停 / 继续 |

手枪无限子弹；初始重机枪 120 发、火箭 8 发、手榴弹 8 枚。特殊武器打空后自动切回手枪。H 箱补充机枪和火箭弹，G 箱补充手榴弹。桥面会逐段爆破；落水后可游动、向上射击并跳回岸边。页面右上方“初始生命”可选 3、5、10、30、99 条（默认 3 条），自动记住选择，下次开局或点击“重新开始”生效。死亡后从最近检查点补满装备重试；生命耗尽则按所选初始生命从头开始。

## 范围与实现

- 原版魂斗罗地图像素与平台坐标；Marco 跑步、跳跃、手枪、重机枪和死亡动画。
- 三种武器、爆炸范围伤害、手榴弹、敌军射击、补给、桥面爆破和通关结算。
- `core.js`：固定 60 Hz 玩法、武器和伤害；`game.js`：输入、动画、音效；`level.js`：地形；`index.html` / `style.css`：界面。
- 复用同目录上级 `20260908-contra-mario` 的 Canvas 架构、AABB 与输入约定，并适配魂斗罗可下穿平台。
- 现已包含完整第一关、两座爆破桥、丛林深坑、三处检查点和堡垒 Boss（双炮口、核心散射、血条与爆炸结算）。物理、敌人出场和数值为重做，非逐帧原版仿真。火箭筒采用 Marco 基础持枪动画加绘制发射器；蹲姿使用已有动画组合。声音使用合金弹头素材。

## 验证与运行

运行 `node check.cjs` 检查武器切换、弹药、投弹、地形、水中脱困、全关地形通行、第二座桥爆破、Boss 实弹伤害与延迟结算、深坑死亡和检查点续关。
可选本地服务：`python -m http.server 18766 --bind 127.0.0.1`，打开 http://127.0.0.1:18766/ 。
`prepare-assets.py` 仅用于素材整理，运行游戏不需要 Python 或 Pillow。
